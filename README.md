# Детектирование дорожных знаков

Учебная практика: сравнение современных моделей компьютерного зрения для задачи детектирования и классификации дорожных знаков на изображениях.

## Датасет
GTSRB (German Traffic Sign Recognition Benchmark), 2500 изображений, 43 класса знаков.

## Модели
- YOLOv8n
- YOLOv10n
- Faster R-CNN
- SSD
- RT-DETR
